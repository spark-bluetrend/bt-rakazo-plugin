# BT 公司助理外掛（Rakazo）

讓 BT 助理連接公司 Google Workspace（Gmail、日曆、雲端硬碟）。

## 安裝（每位同事一次，約 1 分鐘）

1. 打開 BT 助理（https://bot.bluetrend.media 或手機 App）→「整合」→ 右上角「＋」→「從 GitHub」。
2. 貼上本倉庫網址，按「預覽」→「連接」，再按「新增技能」。
3. 在 google-workspace 按「登入」，用自己的 @bluetrend.media 帳號，按「允許」。

本倉庫只有連接器網址與使用說明，沒有任何密碼或金鑰。每位同事只會存取自己的信箱與行事曆。
